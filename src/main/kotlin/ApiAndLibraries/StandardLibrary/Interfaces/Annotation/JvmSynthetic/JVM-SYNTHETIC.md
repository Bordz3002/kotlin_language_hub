# `@JvmSynthetic`
`@JvmSynthetic` makes a Kotlin declaration inaccessible from Java source code, while it remains usable form Kotlin  
This is useful when you have Kotlin Api that contains something intended as an internal helper for Kotlin, but you don't want Java callers to use it directly
## Basic idea
```
Kotlin

@JvmSynthetic
fun internalHelper(){
    println("kotlin only helper")
}
```
Kotlin can still do: 
```
Kotlin

internalHelper()
```
But Java source code cannot normally do:
```
Java

internalHelper(); //inaccessible
```
### Important distinction
`@JvmSynthetic` does not mean: "The function exists on the JVM"  
It still exists in the generated bytecode. The annotation mainly prevents the Java source-level access to it.
